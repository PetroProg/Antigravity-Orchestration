# Skill: /security-sync

1. Прочитай `PORTFOLIO.md` и все файлы в `manifests/` (`*-GEMINI.md`, `*-STATE.md`).
2. Сверь текущие риски каждого проекта с глобальным стандартом безопасности (`security-baseline`).
3. Выдели общие и повторяющиеся задачи по портфелю (секреты и `.env`, запуск Docker-контейнеров от непривилегированного `USER`, параметризация SQL, валидация внешнего ввода и таймауты, очистка логов).
4. Для каждого проекта с открытыми рисками создай или обнови промпт `generated-prompts/<project>-security.md` со структурой:
   - Целевой проект и рекомендуемая модель
   - Цель задачи и выявленные риски
   - Конкретные файлы для проверки в проекте
   - Пошаговый план исправлений
   - Критерии проверки и напоминание обновить `<project>/STATE.md`
5. Выведи краткую итоговую таблицу: проект → ключевые риски → путь к файлу промпта → рекомендуемая модель.
